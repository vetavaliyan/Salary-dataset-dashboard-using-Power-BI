# Salary Analysis Dashboard

This repository contains a comprehensive **Salary Analysis Dashboard** built to visualize and analyze salary trends, job roles, and company locations in the tech/data domain.

## 📊 Features

- **Highest Paying Job Titles:** Bar chart showing which roles earn the most.
- **Salary Category:** Donut chart categorizing salaries into Low, Mid, and High.
- **Salary Trends Over the Years:** See how average salaries have evolved from 2020–2024.
- **Salary by Experience & Year:** Stacked bar chart showing salary distribution by experience and year.
- **Salary by Company Location:** Compare salaries across different regions/locations.
- **Salary Trend for Selected Job:** Detailed yearly salary trends per selected job title.
- **Dynamic Filters:** Filter dashboard by `Company Location` and `Job Title`.

## 🛠️ Technology Used

- **Power BI** (shown in screenshot, can be adapted for other tools)
- Data visualization with interactive charts
- Supports map-based visuals (enable in Power BI settings if needed)

## 🚀 How to Use

1. Clone this repository.
2. Open the dashboard file (`.pbix` or equivalent).
3. Enable map/fill visuals if needed (**Power BI:** File > Options and settings > Options > Global > Security).
4. Use filters to explore salary data by location and job title.
5. Analyze trends, identify top-paying roles, and make data-driven decisions.
